## 1. Что это и где смотреть

Организатор РП (FS-Master — он же пользователь, играет Крюкова) с игроками делает визуальную новеллу по своей телеграм-ролёвке.
- **Название игры:** «Second Empire», подзаголовок «The Spirit of the Great February» (логотип пользователя, 15.10).
- **Объём:** двадцатые годы, по главам. Глава I «Собор»: ноябрь 1922 – 3 сентября 1923, плюс эпилог «осень 1923».
- **Игра для игроков (с 16.10): https://aaboutenko-pixel.github.io/Second-Empire-The-spirit-of-the-Great-February/** — GitHub Pages из репозитория пользователя, выкладка каждым push в `main` (§6). Проверено 16.10 в браузере: титул, логотип, музыка, спрайты грузятся.
- **Запасная страница (артефакт):** https://claude.ai/artifact/TUZp3LhyqCKR1DnSbGRa3X (с 16.10 не обновляется, там версия без полки глав). Это артефакт с доступом «по ссылке», публикуется из `vn-demo/site/sobor-1922.html` вместе с картинками и музыкой (§6). Друзьям пользователь открывает его через меню «Поделиться». Сохранения у каждого свои, в его браузере.
- **Мини-приложение Telegram — подключено в странице 16.10:** `<script src="https://telegram.org/js/telegram-web-app.js">` в шапке; `TG` = `Telegram.WebApp`, только если `platform !== 'unknown'` (в обычном браузере скрипт тоже объявляет объект, но платформа «unknown» — тогда всё как раньше). Внутри Telegram: `ready()`, `expand()`, `disableVerticalSwipes()`; полный экран через `TG.requestFullscreen()` / `exitFullscreen()` (Bot API 8.0, событие `fullscreenChanged` пишет `prefs.fullscreen`), «Выйти» = `TG.close()`. **Полоса Telegram сверху** («✕ Закрыть», «⌄», «⋮») в полноэкранном режиме — рисует сам Telegram, убрать нельзя (пользователь спрашивал 16.10). Пробовали сдвигать сцену под неё по `safeAreaInset`/`contentSafeAreaInset` (и запасной отступ в 20 % экрана) — на телефоне пользователя это «полностью сломало полноэкранный режим», откачено 17.10: сцена снова во весь экран, полоса Telegram ложится поверх. Поэтому **верхняя полоска игры убрана** (17.10): переключатель сцен (был выпадающий список справа вверху, «телепортации») — теперь кнопка **«Сцены»** в быстром меню и вкладка в игровом меню (список сцен кнопками, текущая золотая, щелчок — переход через `go`); подпись места и даты (была слева вверху вместе с названием главы) — **в правом конце строки имени** в текстовом боксе (`.who .pl`, `placeTag()`, и у реплик, и у подсказок карточек; на развилках скрыта). Название главы на сцене больше не показывается. В быстром меню теперь восемь кнопок: Назад, История, Сцены, Пропуск, Авто, Скрыть, Звук, Меню. Порядок в игровом меню (пользователь 17.10): Вернуться, История, Сцены, Настройки, Главное меню; «Выйти из игры» из игрового меню убрана по его же слову 17.10 («не нужно»), выход остался только на титуле. Настройки, открытые с титула, показывают лишь Вернуться и Настройки — без «Главное меню» и без загрузки.

**Замок на сценах для официального релиза (пользователь 17.10):** «пока люди не дойдут до сцены, перейти к ней через «Сцены» нельзя, и название не показывать, чтобы было интересно, а то будут скипать». Сделано 17.10 под флагом **`SCENES_LOCKED` в `build.py`**: сейчас `False` (пользователь тестирует, все сцены открыты); **перед официальным релизом поставить `True`** и пересобрать. При `True` в списке открыты только сцены, чей первый шаг прочитан (`seen`, по отпечаткам шагов) и текущая; остальные — серые кнопки «N · · ·» без названия, не нажимаются. Грабли: отпечаток первого шага сцены меняется при правке этого шага — такая сцена для старых читателей снова «закроется», пока они до неё не дойдут; «Продолжить» при этом работает как обычно. Бот пользователь создаёт сам в @BotFather (инструкция дана 16.10: /newbot → /mybots → Bot Settings → Menu Button → адрес игры); токен мне не нужен. Выкладывать в Telegram пользователь будет после сцены в амбаре; до этого — «бесконечное обновление». Ранее обсуждали:
  - статический хостинг (GitHub Pages; Cloudflare в РФ режут);
  - бот через @BotFather, его создаёт пользователь;
  - сохранения в Telegram CloudStorage.

  Папка `site/` готова к статическому хостингу как есть.

## 2. Решения пользователя (не пересматривать)

### Содержание
- **РП переносится в новеллу как есть: все сцены и реплики по логу.** Главы II и дальше делаются тем же способом.
- **Лог — основа, а не закон.** Пользователь переписывает сцены. Переписанные и вставленные строки помечаются `+` вместо номера.
- **Румынская линия (захват Румынии, протекторат, Мареш) исключена целиком.** Ни сцен, ни упоминаний в репликах.
- **Альтернативные ветки — только пасхалки** на отдельных вопросах. Последствий нет, ветка кончается карточкой «Так в игре не было» с одной кнопкой «Назад к выбору» по центру (кнопку «Как было на самом деле» пользователь убрал 15.10: «бесполезна»). Осталась одна: корона на соборе. **Развилку Росса в Кремле пользователь убрал 15.10** («потом вернём»): её строки в `01_kremlin.txt` закомментированы `// `, сцены `choice_ross` больше нет (28 сцен).
- **Кашубский бунт — реалистично.** Шапка `02_dantsig.txt` объясняет:
  - бунт польских сёл под Картузами;
  - «кашубским» его назвал русофильский листок из Данцига;
  - Кашубский — авантюрист с ~300 добровольцами;
  - Москва открещивается, Лига Наций вывозит добровольцев.

  Финляндия независима, Маннергейм не капитулировал.
- **Глюг — просто «Глюг»**, без «фон».
- **Чины (15.10):** Табуретов, Глюг и Ческидов подписаны «генерал-фельдмаршал» везде, по старому Табелю о рангах; в тексте «маршал» про них заменён на «генерал-фельдмаршал» (указы, ремарки, реплика Крюкова). Табуретов после указов подписан «министр обороны» (пользователь вернул). Павлов — просто «генерал». Пилсудский остаётся «маршал». В указе после собора все трое получают генерал-фельдмаршала, «фельдмаршальские погоны». Список чинов пользователь обещал дать позже отдельным обновлением.
- **Столица Монголии в 1923 — Урга.**
- **Телеграммы: ТЧК только в конце.**
- **Хронология:** собор 1 сентября 1923, взрыв и нападение у Генштаба 2-го, Дума 3-го. Волынь и Варшава — эпилог после Думы. Росс во Владивостоке «за 8 часов» оставлен как есть («забей»).
- **Камео и сцены от игроков вставляются как есть:** правятся только опечатки и знаки, ремарки — наши. Так вставлены сцена Ческидова и сцена ОГПУ Зарывалова (§8).
- **Нынешняя часть — ПРОЛОГ** (16.10). Осень 1923 (Берлин, Вашингтон, Красноярск, Лубянка, Восток) вложена в него: «для целой главы событий мало, пусть пролог идёт 40 минут вместо 30». Основная история начинается с **1927 года**, «абсолютно другие события, очень колоритная»; русско-польская война и Волынь — там. Главу 1927 года не начинать без отмашки.
- **Росс жив.** В логе его персонажа в какой-то момент убили, потому что игрок ушёл; игрок вернулся, Россу прописана большая линия до 1931 года. Любые сведения о смерти Росса из лога выкидывать (16.10).

### Вид
- **Только горизонталь 16:9, как «Бесконечное лето»** (15.10). Вертикальную раскладку для телефона пользователь отменил: она ломала и обрезала спрайты. **Одна вёрстка на комп и телефон, без поворота** (15.10, вечер): телефон боком — сцена во весь экран; телефон вертикально — та же сцена прямая, во всю ширину, тёмные полосы сверху и снизу (пользователь: «нормальная практика»). Поворот сцены на 90° в портрете был ошибкой: игра стояла боком, когда телефон держали прямо.
- **Вёрстка одна, без исключений для экранов** (15.10, вечер, по скриншотам пользователя: «текст поехал, надо одинаково у всех»). Все размеры на сцене — доли её высоты и ширины (`cqh`/`cqw`); пиксельных минимумов шрифта и особых правил для низкой или узкой сцены нет. На маленьком экране всё просто мельче. Быстрое меню — десять кнопок везде.
- **Занавес между сценами — четвёртая попытка, 15.10 вечером,** по просьбе пользователя («резко кидает на событие через три месяца», «начать игру — и она моментально начинается»). Три прежние заставки (14.10) мелькали или давали чёрный экран. Теперь: один элемент `#curtain`, CSS-переходы и таймеры, которые всегда его поднимают (§7). Опубликовано как пример (№89), **ждёт оценки пользователя**.
- **Номера сообщений на экране не показывать.** В файлах сценария они остаются, для нас.
- **Интерфейс как в Ren'Py, но без слотов сохранений** (15.10, вечер: «какой смысл, если есть выбор сцены»):
  - быстрое меню внизу, семь кнопок: Назад · История · Пропуск · Авто · Скрыть · Звук · Меню;
  - игровое меню (Esc, правая кнопка, «Меню»): История · Настройки · Главное меню · Вернуться;
  - сохранение одно — автоматическое на каждом шаге, на титуле «Продолжить». Слоты, Б.Сохр и Б.Загр удалены вместе с кодом.
- **Окно текста — тень от нижнего края, без рамки.** Реплики:
  - слова не прыгают при печати;
  - текст не вылезает за окно и не мельчает;
  - длинное идёт частями.
- **Карточки (газеты, телеграммы, письма, документы) не прокручиваются и не обрезаются:** шрифт карточки ужимается сам.
- **Окно текста одно и то же под карточками и под репликами** (15.10 вечером: «затемнение на карточках ниже, чем в диалогах, некрасиво»). Раньше под карточкой окно было 19cqh.
- **Подписи над репликой — только фамилия** («Пилсудский», «Кулидж»). У безымянных — роль: «Казак», «Врач», «Голоса из толпы».
- **Луненко в амбаре по центру.**
- **Версия для игроков — «версия 1.0»**, мелко в правом нижнем углу главного экрана и игрового меню, без даты и «беты». 1.1 — когда пролог выйдет в Telegram (16.10); дальше по правкам.

  Номер публикации артефакта («версия 69» и т. п.) — только наш.

## 7. Как устроена страница (шаблон `sobor-1922.tpl.html`)

### Сцена и размеры
- Сцена 16:9 — контейнер (`container-type:size`), размеры в `cqh`/`cqw`.
- **Телефон вертикально:** `@media (orientation: portrait)` — сцена прямая, `width:100%`, по центру экрана, сверху и снизу фон страницы. Никаких поворотов: страница идёт за ориентацией телефона.
- **Телефон боком** (`landscape` и высота ≤ 500 px): сцена без полей на всю высоту.
- **Все размеры — в `cqh`/`cqw`**, без `max(Npx, …)` и без `@container`-правил для низкой или узкой сцены (убраны 15.10 вечером, их было 44 и 2). Если понадобится новый размер — только доли сцены.
- Всё, что меряет сцену, берёт её **собственные** координаты (`stageY`, `offsetWidth/offsetHeight`), а не экранные.
- «Полный экран» в настройках на Android ещё и закрепляет альбомную ориентацию. Для мини-приложения Telegram есть `WebApp.lockOrientation()` (Bot API 8.0) — ставить при интеграции бота.

### Занавес (`#curtain`, `withCurtain(text, apply)`)
- Когда: «Начать» и «Продолжить» с титула; шаг вперёд на первый шаг сцены, у которой поле места/даты (`p`, третье поле `==`) отличается от предыдущего шага. Не показывается: внутри сцены, между сценами с одинаковым `p` (Кремль → развилка Росса), при «Назад», при пропуске (Ctrl/Tab), при прыжке через выбор сцены или развилку.
- Как: чернота опускается 0,45 с → под ней меняется шаг (`goNow`) → подпись (`p`, запятые заменены на « · », капителью) 0,5 с проявляется, держится 1,7 с, гаснет 0,42 с → занавес поднимается 0,9 с. Все переходы по `setTimeout`, так что чёрный экран не зависает; `advance()` во время занавеса ничего не делает.
- Подпись берётся из заголовка сцены как есть. Чтобы написать своё («Три месяца спустя»), надо добавить поле в формат `==` (scenario.py) и подставлять его вместо `p` — пока не сделано.
- Проверено: старт («Пролог · 1918–1922» → первая газета), граница Кремль → Поморье с подписью, назад без занавеса, Кремль → развилка без занавеса. Консоль чистая.

```
title Глава I · Собор | ноябрь 1922 — сентябрь 1923 | <музыка титула>
== kremlin | Кремль: съезд | Кремль, 16 ноября 1922      сцена: id | пункт списка | место вверху
@bg kremlin_zal   @on taburetov kryukov ross   @x ross=64   @e ross=sad   @id canon   @role kryukov=император
@fx dust|snow|rain|embers|smoke|none   @shake  @flash   @sfx explosion|shot|hit   @cg id … @cg   @music Название   (@music пусто = тишина)
757 ross.angry: Реплика.        номер сообщения, кто, эмоция (держится до смены)
757 > Описание.   + вместо номера — строки нет в логе;  ~ — альтернатива;  757+ — сокращено/склеено
paper 66 | Мачта | дата | Заголовок    (ниже абзацы, "> " — цитата, "= " — подпись под карточкой)
wire N | от кого | кому   /   letter N | обращение | подпись   /   doc N | Название (номер можно не ставить)
? 786 Вопрос?  + строки "* текст -> id"

                      "текст | имя" — строка без портрета; кнопок нет, в конце — титул; перед ним @id credits и @music)
```

**Грабли:**
- Во встроенном браузере приложения Claude **полный экран не работает вовсе**: `requestFullscreen()` вызывается, но обещание не завершается и `fullscreenElement` остаётся пустым (проверено 17.10 с настоящим щелчком). Пользователь дважды принимал это за поломку игры; проверять полный экран только в обычном браузере или в Telegram. Там же HTML с GitHub Pages кэшируется на 10 минут (`Cache-Control: max-age=600`) — после выкладки пользователь может видеть старую страницу; `?1` в адресе обходит.
- Эмоция протекает через границы сцен и из пасхалки в канон. На входе в сцену ставить `@e`.
- Тело карточки идёт до пустой строки или до следующей команды.
- `@on` сбрасывает `@x`.
- Говорящий персонаж с картинкой сам на сцену не выходит: без `@on` он говорит за кадром. Так было с Пилсудским, пока его не вывели `@on pielsudsky`.
